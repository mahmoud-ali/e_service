استيراد مستفيدي الوقود من ملف إكسل / CSV

قم برفع ملف Excel (.xlsx) أو ملف CSV يحتوي على قائمة مستفيدي الوقود. سيقوم النظام بإنشاء المستفيدين الجدد وتحديث بيانات المستفيدين الحاليين تلقائياً.

الأعمدة المتوقعة في الملف (يمكن ترتيبها بأي نسق):

  • اسم المستفيد / Beneficiary Name (إجباري في حال عدم وجود كود الموظف)
  • كود الموظف / Employee Code / Code (ربط تلقائي مع الموارد البشرية)
  • رقم بطاقة الوقود / Card Number
  • البريد الإلكتروني / Email
  • الإدارة / القسم / Department
  • الوظيفة / Job Title
  • حصة البنزين / Petrol Gallons / Petrol (بالجالون)
  • حصة الجازولين / Diesel Gallons / Diesel (بالجالون)
  • مفعل / Active (1/0 أو نعم/لا)
